Cyber Threat Analytics Platform with Incident Visualization System
Data Visualization Internship Project
This repository contains the documentation and milestone presentations for our Cyber Threat Analytics project developed as part of the Data Visualization Internship.

Project Overview
The project focuses on analyzing cybersecurity attack data and creating meaningful visualizations to identify cyber threats, security risks, attack patterns, and high-risk areas.

Dataset
The project uses a cybersecurity attacks dataset containing information related to:

Attack Types
Severity Levels
Action Taken
Anomaly Scores
Malware Indicators
Firewall Logs
IDS/IPS Alerts
Proxy Information
Location and Timestamp data
Milestones
Milestone 1
Project documentation and initial project overview.

Milestone 2
Data preprocessing, data cleaning, handling missing values, data types, outliers, encoding, and feature engineering.

Milestone 3
Data visualization patterns and analysis of cybersecurity data.

Milestone 4
Advanced data visualization using Power BI, including Security Risk Assessment and cybersecurity dashboard development.
